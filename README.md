# Сайт Профсоюза 69 — Тверская область

Полнофункциональный сайт профсоюза с панелью администратора.

## Требования

- PHP 8.0 или новее
- Расширения PHP: `pdo_sqlite`, `fileinfo`, `gd`
- Права на запись в папки: `data/`, `uploads/`

## Установка

1. Скопируйте все файлы на хостинг (в корень сайта или в папку)
2. Убедитесь, что папки `data/` и `uploads/` доступны для записи (chmod 755)
3. Откройте в браузере: `http://ваш-сайт/setup.php`
4. После установки:
   - Войдите в панель администратора
   - Смените пароль в разделе «Сменить пароль»
   - **Удалите файл `setup.php` с сервера!**

## Данные для входа (по умолчанию)

- Логин: `admin`
- Пароль: `admin123`

## Структура сайта

```
union-site/
├── index.php          — Главная страница
├── news.php           — Список новостей
├── news-single.php    — Одна новость
├── about.php          — О профсоюзе
├── docs.php           — Документы
├── help.php           — Помощь членам
├── contacts.php       — Контакты
├── gallery.php        — Галерея
├── admin/             — Панель администратора
│   ├── index.php      — Дашборд
│   ├── login.php      — Вход
│   ├── news.php       — Управление новостями
│   ├── gallery.php    — Управление галереей
│   ├── members.php    — Руководство
│   ├── organizations  — Первичные организации
│   ├── documents.php  — Документы
│   ├── forms.php      — Обращения
│   ├── help.php       — FAQ
│   └── settings.php   — Настройки сайта
├── assets/            — CSS, JS, изображения
├── uploads/           — Загружаемые файлы
└── data/              — База данных SQLite
```

## Возможности панели администратора

| Раздел | Что можно делать |
|--------|-----------------|
| Новости | Добавлять, редактировать, удалять, публиковать/скрывать |
| Галерея | Загружать фото, добавлять видео (YouTube), управлять |
| Документы | Загружать PDF/DOC/DOCX, организовывать по категориям |
| Руководство | Управлять составом руководства с фото |
| Организации | Вести список первичных организаций |
| FAQ | Управлять вопросами-ответами |
| Обращения | Просматривать и обрабатывать заявки с формы |
| Настройки | Менять всю контактную информацию, статистику, тексты |
| Пароль | Менять пароль администратора |

## Настройка

Основные параметры в файле `config.php`:
- `BASE_URL` — базовый URL сайта (для подпапки: `/union-site`)
- `DEBUG_MODE` — режим отладки (false на боевом сервере)
